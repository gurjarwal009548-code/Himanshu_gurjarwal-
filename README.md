# AnimatePro — 2D Animation Course Website

## Files
- `index.html` — website structure/content
- `style.css` — design/responsive layout
- `script.js` — mobile menu interaction

## Before publishing
1. Replace `AnimatePro` with your real brand/course name.
2. Replace the WhatsApp number in `index.html`.
3. Replace price, curriculum, contact details and course information.
4. Add your real logo/images if needed.

## Run on phone/PC
Open `index.html` in a browser.

## Publish free
Use GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository.
3. Upload `index.html`, `style.css`, `script.js`.
4. Open repository Settings → Pages.
5. Select Deploy from a branch → `main` → `/root`.
6. Save. GitHub will provide your live website address.
